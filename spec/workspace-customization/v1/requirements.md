# Workspace customization schema: requirements

Normative. Requirements use *EARS* patterns.

## Precedence and reading rules

- `schemas/customization.schema.json` ("the schema") and `interfaces.json`
  prevail over this file and over `journeys.md`. Where they differ, the schema
  and `interfaces.json` win, and the difference is a specification defect
  that is fixed in `workspace-customization@v2`.
- The sources cited in `overview.md` (chapters 2, 5, 8 and 19 of the v1
  product description) are provenance only. They do not add to or override
  this version.
- This version defines the vocabulary of `customizations.aibox`. The
  behaviour behind each key belongs to the phase that interprets it
  (`interfaces.json` `sections`); this version does not define it.

**Verified by** names the journey of `journeys.md` that verifies the
requirement. "Not separately verified" marks an obligation that no check
exercises on its own.

## Role

| ID | Requirement | Verified by |
|---|---|---|
| WC-001 | `customizations.aibox` in `devcontainer.json` shall be optional, product-specific metadata read only by software that elects to interpret it; it shall not be a Dev Container standard field, an upstream Feature, a generic customization facility or a second project entry point. | Not separately verified |
| WC-002 | `customizations.aibox` shall carry only aibox-specific preferences that need a runtime interpreter after standard properties, Feature options and native tool files have been considered; it shall never install tools and shall not carry image, install, security or lifecycle settings. | Not separately verified |
| WC-003 | A preference in `customizations.aibox` shall not also be defined as a Feature option, and no authoritative value shall be duplicated across Feature options and this namespace. | Not separately verified |
| WC-004 | A native-only project shall be able to omit `customizations.aibox` entirely. | J-WC-04 (the `minimal` example has none) |

## Shape

| ID | Requirement | Verified by |
|---|---|---|
| WC-010 | The schema shall define an object with the required member `schemaVersion`, whose only value is `"1"`, and the optional sections `workspace`, `harnesses`, `latex` and `diagnostics`, and no other member. | J-WC-01, J-WC-03 |
| WC-011 | The schema shall be closed: an unknown key, an unknown `schemaVersion`, a value outside a named enumeration and a `null` value shall fail validation. | J-WC-03, J-WC-04 |
| WC-012 | `workspace` shall declare each of the 115 v0 `customization.*` leaf paths of `ledger/v0-parity/configuration.json` with its existing name and primitive type, and the new opt-in sections `sidebar` and `review`. | J-WC-02 |
| WC-013 | `harnesses.order` and `harnesses.launch.<name>.enabled` shall express launch intent, not installation. | Not separately verified |
| WC-014 | `latex` and `diagnostics` shall contain only aibox-owned UX and diagnostic preferences; preview network and service settings are native Compose input, not keys of this schema. | J-WC-01 (generated without them) |
| WC-015 | Schema validity shall not be taken as proof of effective-value equivalence; defaults, cross-field rules and semantic constraints are validated by the interpreting phase. | Not separately verified |

## Generation and change

| ID | Requirement | Verified by |
|---|---|---|
| WC-020 | The schema shall be generated by `scripts/spec/inventory.mjs` from the v0 baseline inventory, and the committed schema shall equal the generator's output. | J-WC-01 |
| WC-021 | Where a v0 option gained closed values after the v0 baseline (`workspace.tmux.layout_switch.style`: `menu`, `table`; `workspace.tmux.notifications.protocol`: `osc-9`, `bell`), the schema shall keep those values closed. | J-WC-01 |
| WC-022 | When a key is added, removed or moved, or an enumeration changes, the schema, the ledger, the converter, the maintained examples with their option comments, and the fixtures shall change together in one new version of this specification. | J-WC-05 (examples regenerate from the schema); the rest is not separately verified |
