# Native workspace starters: overview

This file is not normative. The contract is `requirements.md`,
`interfaces.json`, `journeys.md` and `schemas/customization.schema.json`.

## Goal

Give a user a directly runnable native Dev Container workspace, minimal or
curated, with a persistent non-root home, that works with the upstream Dev
Container CLI alone and leaves every file to the project afterwards. Roadmap
item V1-04.

## Origin of this version

This is a thin specification (owner decision on issue #504, 2026-11-15). V1-04
was implemented before the
[specification layout standard](../../../.standards/specification-layout-and-lifecycle.md)
was adopted and before phases had a frozen test-ready contract. This version
records the obligations V1-04 implemented and verified, without changing
them:

- Chapter 8 of the v1 product description,
  ["Starter distribution and upstream interoperability"](../../../docs/product/v1/08-native-artifacts.md#starter-distribution-and-upstream-interoperability)
  and ["Native configuration example"](../../../docs/product/v1/08-native-artifacts.md#native-configuration-example).
- Chapter 12,
  ["Named environments and persistence"](../../../docs/product/v1/12-migration-and-state.md#named-environments-and-persistence),
  for the default home.
- The checks of `scripts/verify-v1-04.sh`, `scripts/spec/validate-contracts.py`
  and `scripts/verify-v1-04-host.py`, which define what V1-04 verified.

`schemas/customization.schema.json` is byte-identical to the former
`spec/v1/customization.schema.json` except for its `$id`, which names the new
path; it is still generated by `scripts/spec/inventory.mjs` from the v0
ledger. The maintained examples stay in `examples/` at the repository root,
because later phases change them
([path map](../../../docs/engineering/spec-layout-migration.md)); the
Templates stay in `templates/src/` as product source.

## Boundaries

- Optional tools are selected as native Features; their contract is
  `tool-catalog@v1`. The `customized` example selects the Feature recorded in
  that specification's `fixtures/v1-05-native-features.json`.
- No published Template reference exists yet; OCI Template publication is a
  separate release task.
- The UX keys of `customizations.aibox` are declared by the closed schema
  here; their behaviour belongs to later phases (V1-11, V1-12) and to
  `settings-and-logging@v1` for `workspace.theme`, `.mode` and `.layout`.
