This catalogue is generated from the same audited palette source used to create
the managed tmux, Vim, Yazi, shell-tool, and supported coding-agent themes.
The terminal examples are HTML: the colors are exact, the text remains
selectable, and no host-terminal screenshot or recording is involved.

Use the [theme chooser]({{< relref "chooser" >}}) to narrow the catalogue by
overall appearance and contrast, or review [tool support]({{< relref "tool-support" >}})
to see how the semantic roles map into each generated integration.

The label after the mode is the configurable variant. “Default variant” means
leave `variant = ""`; only named alternatives such as `deep`, `dimmed`, or
`max` need a value. General appearance is a qualitative reading of the whole
terminal specimen, not the hue of its accent token.
