# Architecture decision records

Decisions about this repository's architecture and development setup, as
*ADR according to Nygard* (context, decision, consequences). One file per
decision, numbered in order: `NNNN-short-title.md`. An accepted ADR is not
edited; a later ADR supersedes it and says so.

Decisions made before 2026-11-11 are processkit DecisionRecords (`DEC-*`)
under [`archive/processkit/decisions/`](../../archive/processkit/decisions/).
They stay valid and are cited by their ID.
